# xianzheng_skills

语文教学与教研场景下的 Cursor Agent Skills 合集。

## 目录结构

```
xianzheng_skills/
├── 教育家skills/     # 中外教育家思维框架蒸馏（可复用的人物视角 Skill）
└── PPT制作skills/    # AI PPT 制作相关 Skills
```

### 教育家skills

将教育家的核心思想、决策启发式与表达风格蒸馏为结构化 Skill，便于在教研、备课、评课中切换视角分析问题。

涵盖中国语文教育家（如孙绍振、温儒敏、钱梦龙、魏书生等）与国际教育/读写研究者（如 Louise Rosenblatt、Paulo Freire、Grant Wiggins 等）。

详见：[教育家skills/README.md](教育家skills/README.md)

### PPT制作skills

汇集多款 AI PPT 制作技能，覆盖原生 PowerPoint、网页 PPT、设计生成等场景。

详见：[PPT制作skills/README.md](PPT制作skills/README.md)

## 使用方式

在 Cursor 中将对应 Skill 目录加入 Agent Skills，或按各子目录内的 `SKILL.md` 说明启用。
